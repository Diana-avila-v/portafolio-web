Datamart Grooming de PetCare 360

Datamart y dashboard para analizar los servicios de grooming de una empresa de cuidado de mascotas: ingresos, utilidad, servicios más rentables y clientes.

Problema que resuelve
Los datos vivían en un sistema transaccional y la gerencia no podía ver ingresos, márgenes ni tendencias por sucursal, servicio o canal.
Tecnologías
  • SQL Server
  • SSIS
  • SSAS
  • Power BI

Mi aporte

Modelo dimensional en esquema estrella (una tabla de hechos y siete dimensiones) y dashboard de tres páginas en Power BI conectado en vivo al cubo. El ETL y el cubo OLAP se desarrollaron en equipo.

Qué aprendí

A separar el modelo transaccional del analítico, a definir KPIs como margen de utilidad y crecimiento de ingresos, y a detectar duplicados que inflaban las cantidades.

Sistema de Monitoreo Ambiental con Arduino

Sistema web para monitorear condiciones ambientales mediante Arduino, registrando niveles de luz y sonido y permitiendo consultar las mediciones desde un dashboard interactivo.

Problema que resuelve
Facilita la captura y consulta de mediciones ambientales obtenidas mediante sensores de luz y sonido, centralizando los datos en una aplicación web para su seguimiento y análisis.
Tecnologías
  • Arduino
  • Python
  • Flask
  • SQLite
  • JavaScript
  • TailwindCSS

Mi aporte

Desarrollo de la aplicación web con Flask, integración con Arduino mediante comunicación serial, gestión de mediciones y lugares, almacenamiento de datos en SQLite y creación de un dashboard para visualizar estadísticas.

Qué aprendí

Aprendí a integrar hardware con una aplicación web, gestionar la comunicación serial entre Arduino y Python, estructurar una aplicación Flask por módulos y trabajar con almacenamiento y visualización de datos.

Repositorio

colorClassifyAI

Aplicación web que detecta y clasifica el color dominante de una imagen mediante un modelo de aprendizaje automático entrenado con un dataset propio.

Problema que resuelve
Identificar de forma automática el color de un objeto en una imagen o en video, sin que una persona tenga que revisarlo a simple vista.
Tecnologías
  • Python
  • Flask
  • TensorFlow / Keras
  • OpenCV

Mi aporte

Generación del dataset de imágenes por color, entrenamiento del modelo de clasificación y desarrollo de la aplicación web con Flask para probarlo con imágenes y cámara en vivo.

Qué aprendí

A entrenar y ajustar un modelo de clasificación de imágenes, y a conectar un modelo de IA con una aplicación web real.

En desarrollo

Sistema de gestión de bidones

Sistema para controlar los bidones de agua de una empresa distribuidora: a quién se prestaron, quién tiene deudas y en qué estado están.

Problema que resuelve
La empresa lleva todo en papel y no puede saber qué bidones están en la calle, qué clientes deben ni quiénes compran más.
Tecnologías
  • Flutter
  • Levantamiento de requerimientos

Mi aporte

Trabajo en un equipo de tres personas. Definí el problema y los requerimientos: trazabilidad de bidones, morosidad, segmentación de clientes y alertas de bidones en riesgo.

Qué estoy aprendiendo

A delimitar el alcance de una tesis y a justificarla con datos reales de la empresa.

Design System / Componentes

Las decisiones visuales y los componentes que se usan en este portafolio. Cambia el tema con el botón de la barra superior y los valores de color se actualizan.

Colores

Cada color es una CSS Custom Property definida en css/tokens.css. El valor que ves debajo se lee del tema activo.

  • Primary

    --color-primary #0a7b83

  • Secondary

    --color-secondary #5b3fd1

  • Accent

    --color-accent #f2b705

  • Background

    --color-background #f1f6f6

  • Surface

    --color-surface #ffffff

  • Surface alt

    --color-surface-alt #e4eded

  • Text

    --color-text #14222b

  • Text muted

    --color-text-muted #4f6270

  • Border

    --color-border #cbd9da

  • Success

    --color-success #1b7a4e

  • Danger

    --color-danger #b42335

Tipografía

Títulos en Bricolage Grotesque y texto corrido en IBM Plex Sans. Los tamaños son variables y los títulos grandes se adaptan al ancho de pantalla.

Título principal

h1: Bricolage Grotesque Bold, --text-3xl

Título de sección

h2: Bricolage Grotesque Bold, --text-2xl

Título de bloque

h3: Bricolage Grotesque Bold, --text-xl

Párrafo de lectura. Uso una altura de línea generosa y líneas de menos de 80 caracteres para que el texto se lea con comodidad.

Párrafo: IBM Plex Sans Regular, --text-base

Texto secundario para descripciones y notas de apoyo.

Texto secundario: --color-text-muted

Enlace dentro de un párrafo

Enlace: --color-link, subrayado

Espaciado

Una escala de seis pasos que se usa en márgenes, rellenos y separaciones entre elementos.

  • --space-xs 0.25rem
  • --space-sm 0.5rem
  • --space-md 1rem
  • --space-lg 1.5rem
  • --space-xl 3rem
  • --space-2xl 4.5rem

Bordes, radios y sombras

Cada nivel de importancia tiene su propio radio: pequeño para controles, medio para tarjetas y grande para imágenes y ventanas.

  • --radius-sm 0.375rem
  • --radius-md 0.75rem
  • --radius-lg 1.25rem
  • --radius-pill 999px
  • --shadow-card
  • --shadow-raised

Análisis de vulnerabilidades con OWASP ZAP

  • OWASP ZAP
  • Juice Shop
  • Seguridad web

Qué aprendí
